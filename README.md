# Booktrail
# Booktrail v4.6.0

Booktrail 是一款运行于 **Kindle 原系统**的本地阅读统计工具，用于记录和整理你的阅读轨迹。

## 功能

* 📚 **阅读记录**：自动记录 Kindle 上的阅读时间与阅读会话
* 📖 **书库统计**：按书籍查看阅读进度与累计阅读时长
* 📅 **阅读统计**：查看每日、每周、每月及年度阅读数据
* 📊 **阅读分析**：通过统计页面了解自己的阅读习惯与阅读量
* 🕐 **实时记录**：后台自动采集阅读数据，无需手动操作
* 💾 **本地存储**：阅读数据保存在 Kindle 本地，不依赖云服务
* ⚡ **轻量运行**：针对 Kindle 硬件环境设计，尽量减少资源占用

## 安装

本版本提供 Kindle 越狱环境使用的安装包：

**`Booktrail-4.6.0.zip`**

## 适用环境

* Kindle（5.17.1.0可用） 越狱设备
* Kindle 原生阅读系统
* KUAL安装环境

> Booktrail 专注于 Kindle 原生阅读体验，不需要更换阅读器，也不会改变 Kindle 原有的阅读方式。
